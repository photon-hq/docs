This guide registers a Fusor webhook and verifies the first delivery with Node
or Bun. Your endpoint must be a public HTTPS URL. For local development, expose
your server with a tunnel such as [ngrok](https://ngrok.com/).

## 1. Register an endpoint

Authenticate with your Spectrum project id and project secret:

```sh
curl -X POST "https://spectrum.photon.codes/projects/$PROJECT_ID/webhooks/" \
  -u "$PROJECT_ID:$PROJECT_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "webhookUrl": "https://example.com/spectrum-webhook",
    "eventTypes": ["message.received"],
    "failureNotificationEmail": "webhooks@example.com"
  }'
```

The response includes two one-time secrets:

```json
{
  "succeed": true,
  "data": {
    "id": "6a4d2e8c-7b1f-4d3a-9a8e-2c5d6f7e8a9b",
    "webhookUrl": "https://example.com/spectrum-webhook",
    "deliveryMode": "fusor",
    "eventTypes": ["message.received"],
    "enabled": true,
    "status": "active",
    "failureNotificationEmail": "webhooks@example.com",
    "signingSecret": "a3f8e29b...5c7e9b2d",
    "standardSigningSecret": "whsec_YWJj...",
    "disabledAt": null,
    "disabledReason": null,
    "createdAt": "2026-08-03T20:00:00Z",
    "updatedAt": "2026-08-03T20:00:00Z"
  }
}
```

Store `standardSigningSecret` in your secret manager. It is shown only at
creation or rotation. `signingSecret` exists for consumers of the legacy
`X-Spectrum-Signature` header; new integrations should use the `whsec_` secret.

## 2. Verify the raw request

The following Hono handler verifies any of the space-delimited signatures sent
during key rotation. It signs the exact request bytes before parsing JSON.
Implement the imported `enqueue(event, id)` function with your durable queue.
Use `id` as a unique key so retries do not repeat non-idempotent work.

```ts webhook.ts
import { createHmac, timingSafeEqual } from "node:crypto";
import { Hono } from "hono";
import { enqueue } from "./queue";

export const app = new Hono();
const secret = process.env.SPECTRUM_WEBHOOK_SECRET!;
const toleranceSeconds = 5 * 60;

function verify(
  rawBody: Uint8Array,
  id: string,
  timestamp: string,
  signatureHeader: string,
): boolean {
  const timestampNumber = Number(timestamp);
  const age = Math.abs(Math.floor(Date.now() / 1000) - timestampNumber);
  if (!Number.isInteger(timestampNumber) || age > toleranceSeconds) return false;

  const key = Buffer.from(secret.replace(/^whsec_/, ""), "base64");
  const expected = createHmac("sha256", key)
    .update(`${id}.${timestamp}.`)
    .update(rawBody)
    .digest("base64");

  return signatureHeader.split(" ").some((candidate) => {
    const [version, digest] = candidate.split(",", 2);
    if (version !== "v1" || !digest) return false;
    const actual = Buffer.from(digest);
    const wanted = Buffer.from(expected);
    return actual.length === wanted.length && timingSafeEqual(actual, wanted);
  });
}

app.post("/spectrum-webhook", async (c) => {
  const id = c.req.header("webhook-id");
  const timestamp = c.req.header("webhook-timestamp");
  const signatures = c.req.header("webhook-signature");
  const rawBody = new Uint8Array(await c.req.raw.arrayBuffer());

  if (!id || !timestamp || !signatures) return c.text("missing headers", 400);
  if (!verify(rawBody, id, timestamp, signatures)) {
    return c.text("invalid signature", 401);
  }

  // Insert `id` into a unique-key store before doing non-idempotent work.
  const event = JSON.parse(new TextDecoder().decode(rawBody));
  await enqueue(event, id);
  return c.text("ok", 200);
});
```

<Warning>
Do not call `json()` before verification. Parsing and reserializing the body can
change its bytes and invalidate the signature.
</Warning>

## 3. Receive an event

Send a message through an enabled provider. Spectrum delivers a
`message.received` event:

```json
{
  "type": "message.received",
  "timestamp": "2026-08-03T20:15:30.123Z",
  "schemaVersion": 1,
  "eventId": "0198f123-4567-7000-8000-123456789abc",
  "projectId": "2c8f1234-5678-4000-8000-123456789abc",
  "platform": "whatsapp",
  "receivedAt": "2026-08-03T20:15:30.123Z",
  "request": {
    "method": "POST",
    "path": "/events",
    "headers": { "content-type": "application/json" },
    "bodyEncoding": "json",
    "body": { "message": "hello" },
    "rawBodyBase64": "eyJtZXNzYWdlIjoiaGVsbG8ifQ=="
  }
}
```

Return `2xx` after verification and durable enqueueing. Delivery is at least
once, so deduplicate with `webhook-id` even if the first request succeeds.
